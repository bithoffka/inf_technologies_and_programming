# Отчёт о лабораторной работе №3 по дисциплине "Информационные технологии и программирование"

### *Ход работы:*

Вариант №2, сайт о воображаемой поездке в другую страну

![Скриншот сайта](https://github.com/bithoffka/inf_technologies_and_programming/blob/main/lab3/media/page_photo.png?raw=true)

Сайт описан в двух файлах (HTML и CSS)
### *HTML:*
![HTML-код](https://github.com/bithoffka/inf_technologies_and_programming/blob/main/lab3/media/html_code_photo.png?raw=true)

>Краткое описание кода:

Создал базовую структуру HTML-документа, указав русский язык страницы через атрибут `lang="ru"`. В секции `<head>` настроил кодировку UTF-8, добавил метатег `viewport` для корректного масштабирования на мобильных устройствах, задал заголовок вкладки окна браузера и подключил внешний файл стилей `style.css` с помощью тега `<link>`. В теле документа `<body>` разместил главный заголовок первого уровня `<h1>` с названием страны. Для логической группировки контента создал блочный контейнер `<div>` с классом `card`, внутри которого разместил информацию о трех городах поездки. Для названия каждого города использовал заголовки второго уровня `<h2>`, а текстовое описание впечатлений обернул в теги абзацев `<p>`.

### *CSS:*
![CSS-код](https://github.com/bithoffka/inf_technologies_and_programming/blob/main/lab3/media/css_code_photo.png?raw=true)
>Краткое описание кода:

Задал базовые стили для селектора `body`, установив семейство шрифтов Arial, светло-розовый цвет фона, обнулив внешние отступы и добавив внутреннее поле в 30 пикселей. Для главного заголовка `h1` настроил выравнивание по центру, преобразование текста в верхний регистр, темно-красный цвет, а также задал межбуквенный интервал, размер шрифта и легкую тень. Стилизовал контейнер `.card`, ограничив его максимальную ширину в 600 пикселей, отцентрировал его по горизонтали с помощью `margin: 0 auto`, установил белый фон, скруглил углы и добавил тень блока для эффекта объема. Для заголовков `h2` внутри карточки задал красный акцентный цвет, настроил отступы и добавил декоративную нижнюю границу. С помощью псевдокласса `:first-child` обнулил верхний отступ у первого подзаголовка для аккуратного выравнивания внутри контейнера. Для абзацев `.card p` настроил межстрочный интервал, цвет текста и выравнивание по ширине для улучшения читаемости, а используя псевдокласс `:last-child`, убрал нижний отступ у последнего абзаца, чтобы избежать появления лишнего пустого пространства внизу карточки.
